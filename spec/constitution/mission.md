# Misión del Proyecto: GitHub Trending CLI

## Propósito
Proporcionar una herramienta CLI eficiente, ligera y amigable que consulte la API REST de GitHub para filtrar y visualizar los repositorios en tendencia según rangos de tiempo configurables.

## Audiencia Objetivo
Desarrolladores y entusiastas del código abierto que buscan descubrir proyectos populares desde la terminal sin necesidad de abrir el navegador.

## Objetivos Clave
- Ofrecer una experiencia de línea de comandos rápida y sin fricción.
- Mantener la herramienta ligera y sin dependencias pesadas.
- Garantizar mensajes de error amigables e intuitivos.
